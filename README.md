
# ⚡ DSA Practice Tracker

A simple and interactive web application to track
Data Structures and Algorithms practice.

## Features

- Add coding problems
- Track LeetCode, CodeChef, Codeforces and HackerRank
- Categorize problems by topic
- Set problem difficulty
- Mark problems as solved or unsolved
- Filter problems by status and platform
- Track progress through a dashboard
- Save data using browser Local Storage

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
